# Workout Tracker

**Personal project, 2026 – ongoing**

A multi-user app to log gym workouts and follow progress over time, built with AppSheet on top of Google Sheets.

## Features

- **Workout logging:** exercises, sets, reps and load for each session.
- **Load progression:** a time series of the load for each exercise.
- **Strength/volume index:** a custom index combining load and training volume, to compare sessions and periods. Formula: [DESCRIVI LA FORMULA, es. volume = Σ sets × reps × load]
- **Session score:** each session is compared with a rolling baseline of the previous ones, to show whether it was above or below the recent trend. [DESCRIVI: finestra della media mobile, come viene calcolato]
